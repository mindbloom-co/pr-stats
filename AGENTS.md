# Reporting Instructions

Only report to the user in ASD-STE100 Simplified Technical English.

## Notion KPI History

For each KPI refresh, update both the Notion row properties and the page body.
The refresh is not complete until both updates are verified.

- KPI page: https://app.notion.com/p/34547f783bae8189b8a6ca416e26770f
- Fetch the current page and property schema before editing.
- Update Latest Update, Latest Status, and Latest Update Date from the verified report.
- Add a dated entry under the existing Update Log heading, with the newest entry first.
- Include the quarter, data cutoff, actual PRs per engineer, merged PR count,
  denominator and its definition, goal, projected result, and status.
- State exclusions and whether the cutoff day is partial. Grace remains excluded
  unless the user changes this instruction.
- Preserve all previous entries and other page content. Do not replace the body
  with only the latest result.
- Do not add a duplicate entry for the same quarter, cutoff, and report revision.
  For a later correction, add a dated correction with its reason and preserve
  the previous entry.
- When the report is pushed, include a link to that report at its exact Git commit
  so the historical source remains available.
- Read the page back. Check that the row properties and new history entry agree,
  and that previous entries remain present.
